## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- Git
- Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/shivutengali61-crypto/my-portfolio-.git
```

**2. Navigate to the project directory**

```bash
cd my-portfolio-
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:5173
```

*Note: The development command assumes a Vite-based project. Follow the actual package.json scripts if your project uses a different setup.*
